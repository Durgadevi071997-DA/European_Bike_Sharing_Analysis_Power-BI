

# European Bike Sharing Network Analysis





## Project Overview

Bike sharing systems are becoming increasingly popular in Europe because they provide affordable, eco-friendly, and convenient transportation. Cities like Paris, Brussels, Dublin, Lyon, and Seville actively support public bike-sharing services to reduce traffic congestion and pollution.

This dashboard provides a centralized platform to monitor and analyze bike-sharing operations. It helps identify:

Total available stations
Total bikes available
Utilization ratio
Average bikes per station
Station availability status
Contract-wise performance
Geographic distribution of stations

The dashboard enables stakeholders to make data-driven decisions for improving transportation services and operational planning.
## Problem Statement

Bike-sharing companies face several operational challenges in managing transportation systems efficiently.

Some common problems include:

Uneven bike distribution across stations
Lack of bike availability during peak hours
Overcrowded docking stations
Low utilization in certain locations
Difficulty in monitoring station performance
Challenges in predicting customer demand
Inefficient resource allocation

Without proper data analysis, companies may struggle to maintain service quality and operational efficiency.

This project aims to solve these problems using data analytics and dashboard visualization techniques.
## Dashboard Overview

The dashboard provides an interactive visual representation of bike-sharing operations across Europe.

The main sections of the dashboard include:

KPI Cards

## Dashboard Components

1. Status Filter

The left-side filter allows users to select station status:

OPEN
CLOSED

This filter helps analyze operational stations separately.

2. Total Stations by Availability Status

The pie chart displays station availability categories:

Available
No Bikes
Low Availability

This visualization helps identify station conditions and bike shortages.

3. Geographic Map Visualization

The map shows station locations using latitude and longitude coordinates across Europe.

The map helps identify:

Dense bike-sharing regions
High-demand areas
Operational coverage

The visualization supports geographic analysis and smart city planning.

4. Available Bikes by Year

The line chart displays yearly growth in bike availability.

The chart indicates a significant increase in bike availability by 2025.

This trend suggests increasing adoption of bike-sharing services across Europe.

5. Contract Name Wise Availability Status

This section displays contract-wise station performance for cities such as:

Amiens
Besancon
Bruxelles-Capitale
Cergy-Pontoise
Creteil
Dublin

The analysis helps compare operational performance between cities.

6. Station Name Wise Average Availability

This table displays station-level information including:

Station name
Bike availability
Average bikes
Station performance

This helps identify highly utilized and underutilized stations.

7. Average Bikes per Hour by Contract Name

The horizontal bar chart compares average bike availability across different contracts.

Cities like Creteil and Bruxelles-Capitale show higher bike availability.

This analysis supports resource optimization and operational planning.

8. Total Stations by Contract Name

The bar chart displays the number of stations available under each contract.

Lyon has the highest number of stations compared to other cities.

This helps understand city-wise infrastructure expansion.
## Key Insights


Lyon has the highest number of bike-sharing stations.



Bike availability has increased significantly by 2025.



Most stations remain operational and available.



Some stations experience low bike availability.



Creteil shows higher average bikes per hour.



Geographic distribution indicates strong bike-sharing adoption in urban regions.


The utilization ratio of 0.46 indicates moderate system usage efficiency.


European cities are actively expanding sustainable transportation systems.
